# Brian Embroidery

A simple website for Brian Embroidery, a small embroidery business in Kampala, Uganda.
The business stitches logos, names and designs on shirts, uniforms and caps.

## Pages

- Brian.html - Home
- About.html - How the business started and how it works
- Products.html - Shirts, uniforms and caps
- Services.html - Services and prices
- Gallery.html - Photos and videos of real work
- News.html - News and updates
- Faq.html - Frequently asked questions
- Contact.html - Contact form, contacts and map
- Thankyou.html - Message sent page

## How to run it

1. Download all the files.
2. Keep all files in one folder.
3. Keep the images folder in the same folder.
4. Open Brian.html in a browser.

## Built with

- HTML only
- CSS only
- No templates, no frameworks, no builders
